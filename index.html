How the breach check stays private

Your password is hashed with SHA-1 inside your browser. Only the first 5 characters of that hash are sent to the Have I Been Pwned API — never the password, and never the full hash. The API returns every hash suffix that starts with those 5 characters, and the match happens locally on your machine. This is called k-anonymity, and it's the same pattern real breach-monitoring tools use in production.
